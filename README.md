# Kerala Tourism Package Analysis

### TravelTriangle | Web Scraping, Python & Power BI

## 📌 Project Overview
This project focuses on collecting and analyzing Kerala tour package data from the TravelTriangle website using Python web scraping techniques.

The collected data is cleaned, explored and visualized to understand package pricing, discounts, destinations and trip duration. An interactive Power BI dashboard is developed to present key insights.

## 🎯 Project Objectives
- Collect Kerala tour package information using web scraping.
- Clean and preprocess the scraped dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyze package prices, discounts and destinations.
- Build an interactive Power BI dashboard.
- Generate meaningful business insights and recommendations.

## 🛠️ Tools & Technologies
- **Python** – Data collection and analysis
- **Requests** – Sending HTTP requests
- **BeautifulSoup** – Webpage data extraction
- **Pandas & NumPy** – Data cleaning and manipulation
- **Matplotlib & Seaborn** – Data visualization
- **Power BI** – Interactive dashboard development
- **Jupyter Notebook** – Development environment

## 📂 Dataset Overview

The dataset contains the following columns:

| Column | Description |
|---|---|
| Name | Tour package name |
| discount_price | Discounted package price |
| original_price | Original package price |
| Discount_percentage | Discount offered |
| Locations_List | Destinations covered |
| Total_Days | Trip duration |
| No_of_Locations | Number of destinations |
| Package_List | Package category/details |

## ⚙️ Project Workflow

1. **Web Scraping:** Extracted Kerala tour package details from TravelTriangle.
2. **Data Collection:** Collected package information from multiple webpages.
3. **Data Cleaning:** Handled duplicate, missing and inconsistent values.
4. **EDA:** Performed Univariate, Bivariate and Multivariate Analysis.
5. **Visualization:** Explored patterns and relationships using charts.
6. **Dashboard:** Developed an interactive Power BI dashboard.
7. **Insights:** Derived findings and business recommendations.

## 📊 Exploratory Data Analysis

- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Descriptive Statistics
- Distribution Analysis
- Correlation Analysis

## 📈 Power BI Dashboard

The dashboard focuses on:

- Total Packages
- Average Package Price
- Average Discount Percentage
- Average Trip Duration
- Destination Analysis
- Package Pricing Analysis

## 💡 Business Insights & Recommendations

- Understand pricing variations across tour packages.
- Identify discount patterns.
- Explore destination coverage.
- Compare packages based on trip duration.
- Support better package comparison and planning.
